## 6. 复现中确认的真实前提(已回填 01/02)

- ComfyUI 前端对 `easy comfyLoader` 节点实际渲染 12 个 widget(`config_name` 与 token 归一化 combos 不渲染),workflow 的 `widgets_values` 必须按渲染位对齐,否则 `lora_name` 取到错位值(本 kit 已对齐并断言)。
- 服务端 `load_metadata` 无 sidecar 分支会现场计算真实 SHA-256 并写 `<model>.sha256` 缓存(routes.py:252-256);本复现每次跑前清掉 sidecar,保证走真实计算分支。
- Windows 原生直跑时 `os.execv` 是 "spawn+exit" 仿真,父进程监听 socket/SQLite 句柄释放与子进程启动存在竞态(实测两次子进程绑定 8188 失败;金丝雀仍正常落地);**WSL/Linux 真语义下无此问题**,故正式采集在 WSL 完成。此差异属宿主行为,非漏洞本体,报告未据此更改结论。
- Windows Terminal 的标签标题/提示符会暴露本机用户名,正式采集用 `bash --norc` + 中性 `PS1`(命令与输出全部真实,仅环境标识中性化)。
